# 企画提案：中学受験塾 経営シミュレーション（仮題「合格の街 〜塾長シミュレーター〜」）

> 前提資料：[01_reference_analysis.md](./01_reference_analysis.md)（参考ゲームから抽出した12のエッセンス）

---

## 1. コンセプト

> **「今年の一手が、来年の合格実績になる。」**
> 一教室の塾長から始め、生徒を育て、合格実績を積み上げ、地域No.1の進学塾チェーンを築く経営シミュレーション。

コーヒーショップ経営シムの「週次ループ × 明快なレバー × 多層の可視化」を土台にしつつ、
中学受験塾ならではの3つの要素で差別化する。

| 差別化の柱 | 内容 | 対応するエッセンス |
|------------|------|--------------------|
| **① 遅延報酬：合格実績** | 毎週の売上とは別に、年に一度（2月）の入試結果が「合格実績」としてブランド力に変換され、翌年の入塾者数を左右する | E1 を「週次＋年次」の二重ループに拡張 |
| **② 生徒という“育つ顧客”** | 生徒一人ひとりが学力・意欲・志望校・家庭の予算を持ち、週ごとに成長／失速する。顧客が集計値ではなく物語を持つ | E5・E6 を個人単位に深化 |
| **③ 教育と経営のジレンマ** | 詰め込みで実績を上げるか、生徒の心身を守るか。特待生で実績を“買う”か。倫理が選択肢として現れる | E3・E12（倫理軸）を拡張 |

### ターゲット
- 経営シム好き（スマホ／PC の箱庭経営ゲーム層）
- 中学受験経験者・保護者・塾業界関係者（「あるある」で刺さる）
- 想定プレイ：1セッション10〜20分、1年度（約52ターン）で1〜2時間

## 2. ゲームループ

### 2.1 週次ループ（短期：心拍）
```
[月曜] 状況確認：前週P&L・生徒の様子・保護者の声・競合の動き
   ↓
[判断] 月謝／講座開講／講師シフト／施策／個別生徒への対応
   ↓
[週送り] シミュレーション実行（集客・退塾・学力変動・費用計上）
   ↓
[結果] P&L（前週比つき）、生徒数推移、口コミ、イベント発生
```

### 2.2 年次ループ（長期：物語）
塾の1年は2月始まり。カレンダーそのものがゲーム構造を決める。

| 時期 | イベント | プレイヤーの主な判断 |
|------|----------|----------------------|
| 2月 | **入試本番（2/1〜）→ 合格発表 → 新学年スタート** | 実績の発表方法、新年度の価格・クラス編成 |
| 3〜4月 | 春期講習、新規入塾ピーク | 体験授業・広告への投資 |
| 5〜6月 | 学校説明会シーズン、模試 | 志望校別クラスの準備、講師採用 |
| 7〜8月 | **夏期講習**（売上の山・入塾の第2ピーク） | 講習の価格と日程、講師の確保 |
| 9〜11月 | 志望校別特訓、過去問演習 | 6年生への重点投資、退塾防止 |
| 12〜1月 | 冬期講習・正月特訓、出願 | 併願戦略の指導、講師の疲労管理 |

- **季節性（E8）**：コーヒーの温/冷の入れ替わりに相当。時期によって「稼ぐ週」「育てる週」「耐える週」がある。
- **年度末リザルト**：合格者数、偏差値帯別の合格率、生徒の満足度、経営成績を「年度報告書」としてまとめ、翌年の評判に反映。

## 3. 主要システム

### 3.1 コース（商品）— 参考：商品カード（E2）
コーヒーの「温飲料／冷飲料／食品」タブ → **「本科／講習・特訓／個別・オンライン」** タブ。

| 区分 | 例 | 特徴 |
|------|----|------|
| 本科（学年別） | 新4年・新5年・新6年 | 月謝型の安定収益。退塾率が鍵 |
| 季節講習 | 春期・夏期・冬期・正月特訓 | 一時的な売上の山＋新規入塾の入口 |
| 志望校別特訓 | 最難関・難関・中堅・公立一貫（適性検査型） | 高単価。合格実績に直結 |
| 個別指導 | 補習・苦手克服 | 講師1人あたり生徒数が少なく原価高、満足度高 |
| オンライン | 映像授業・オンライン質問 | 低原価・スケールするが満足度は伸びにくい |
| 模試 | 自社模試（外部生も受験可） | 集客装置。受験者が多いほど偏差値の精度＝価値が上がる |

**コースカード**に表示するもの（参考画面4を踏襲）
- 星評価（授業品質）／開講トグル／先週の在籍数と増減
- 原価（講師コスト＋教材費）と粗利率ドーナツ
- 月謝の ± ステッパー
- 追加：**クラス定員と在籍率**、**平均偏差値の推移**

### 3.2 自社教材・自社模試 — 参考：自社ブレンド（E10）
コーヒーの風味五角形 → **教材の五角形**

| 軸 | 効果 |
|----|------|
| 網羅性 | 上位校合格率に寄与 |
| 難度 | 上位層の伸び↑、下位層の脱落↑（トレードオフ） |
| わかりやすさ | 中位層の伸び、満足度↑ |
| 演習量 | 学力↑だが生徒ストレス↑ |
| 入試トレンド対応 | 新傾向問題・適性検査型での得点↑。毎年陳腐化する |

- 市販教材（安いが差別化なし）→ 自社開発（初期費用大・品質を自由に設計）へ移行するのが中盤の目標。
- **豆の相場に相当するのが「講師の時給相場」**。大学生講師の時給は時期・地域で変動する。

### 3.3 生徒シミュレーション（本作の核）
生徒は集計値ではなく、軽量なエージェントとして管理する（教室あたり数十〜数百人）。

| パラメータ | 内容 |
|------------|------|
| 学力（偏差値） | 毎週、授業品質・教材・本人の意欲で変動 |
| 意欲 | 講師との相性、成績の伸び、イベントで上下 |
| ストレス | 授業量・宿題量・成績不振で上昇。閾値超えで退塾・体調不良 |
| 志望校 | 学力と家庭の希望から設定。途中で変更も |
| 家庭の予算 | 講習・特訓の追加受講可否を決める |
| 保護者タイプ | 教育熱心型・放任型・不安型など。口コミの傾向が違う |

- 2月の入試では、学力と志望校の偏差値差から合否を確率判定 → **合格発表演出**。
- 「○○さんが第一志望に合格しました」という個別の物語が、数字（合格実績）とセットで届く（E5の3層可視化）。

### 3.4 講師と教室長 — 参考：店長と業務委任（E9）
**講師**
- 正社員講師（高コスト・高品質・安定）／学生講師（低コスト・品質ばらつき・春に卒業で離脱）
- 能力：授業力・面倒見・専門科目（算国理社）・人気
- 人気講師は競合から**引き抜き**オファーが来る → 待遇で引き止めるか

**教室長**（参考画面の店長に相当）
- 能力4軸：**講師管理／指導・カリキュラム／営業（入塾面談）／倫理**
- 年俸 ± で能力の高い人材を確保
- **業務委任トグル**
  - 講師シフトと時給管理を委任する
  - カリキュラムと料金設定を委任する
  - 生徒募集（広告・体験授業）を委任する
  - 保護者対応・トラブル解決を委任する
- 教室が増えたらプレイヤーは「教室の操作」から「教室長の人事と全社戦略」へ役割が移る。

### 3.5 集客施策 — 参考：マーケティング・キャンペーン（E3・E6）
施策ごとにコスト構造（固定費／変動費／一時費用）と効く層が違う。

| 施策 | コスト型 | 主な効果 | 副作用 |
|------|----------|----------|--------|
| 無料体験授業 | 変動（講師コスト） | 入塾率↑ | 定員圧迫 |
| 合格実績チラシ | 一時費用 | 認知↑（実績が多いほど効く） | 実績が少ないと逆効果 |
| 保護者説明会 | 一時費用 | 教育熱心層の入塾↑ | 教室長の負荷 |
| 自習室開放 | 固定（家賃・監督） | 満足度・学力↑ | 運営コスト |
| 兄弟割・紹介割 | 売上比％ | 継続率・紹介↑ | 単価↓ |
| **特待生制度** | 売上比％（授業料免除） | 上位生の獲得→合格実績↑ | 一般生の不公平感、倫理イベント |
| 送迎・入退室メール | 固定 | 安心安全評価↑ | — |
| Web広告／SNS | 変動 | 若い保護者層への認知 | 炎上リスク |

### 3.6 口コミ・評価 — 参考：お客様レビュー（E6・E12）
- 総合評価＋**4軸：料金・授業・面倒見・安心安全**（参考の「値段・商品・サービス・雰囲気」に対応）
- 顔付きの一言レビューで施策の効果を物語として返す
  - 「夏期講習の体験で先生が丁寧だったので入塾しました」
  - 「宿題が多すぎて子どもが疲れ切っています」← ストレス過多のシグナル
- 合格実績は口コミとは別の**「ブランド力」**として保持（年1回更新）。

### 3.7 地域市場と競合 — 参考：マーケットシェア・都市マップ（E7・E13）
- 市場単位は**駅・沿線エリア**。マップ上に小学校（生徒の供給源）、私立中学、競合塾が配置される。
- 競合はタイプの違う AI 塾（名称はすべてオリジナル）

| 競合タイプ | 強み | 弱み |
|------------|------|------|
| 大手難関型 | 最難関実績・ブランド | 高額・面倒見が薄い・脱落者が出る |
| 面倒見型 | 満足度・継続率 | 上位校実績が弱い |
| 個別指導型 | 柔軟性 | 高単価・集団の競争環境なし |
| 格安オンライン型 | 低価格 | 意欲維持が難しい |

- 地域シェア円グラフで「生徒シェア」と「合格実績シェア」を並べて表示。
- 競合も動く：値下げ攻勢、駅前への新規出店、人気講師の引き抜き。

### 3.8 経理 — 参考：店舗損益計算書（E4）
**売上**：本科授業料／講習・特訓費／教材費／模試受験料／入塾金
**費用**：講師人件費／社員人件費／教材原価／家賃／減価償却／広告宣伝費／本部費
**営業利益 → 税 → 純利益**（各行に前週比、5週推移グラフ）

追加KPI（塾特有）
- 在籍生徒数／入塾数／**退塾数（退塾率）**
- 講師1人あたり生徒数
- 平均偏差値の推移（学年別）

### 3.9 拡大と周辺事業 — 参考：全店舗・マップレイヤー（E10・E11）
**教室展開**：城南 → 城北 → 多摩 → 神奈川 → 埼玉 → 千葉 → 関西 …（エリアごとに競合・家賃・受験熱が異なる）

**周辺施設（中盤〜終盤のコンテンツ）**

| 施設 | 効果 |
|------|------|
| 教材出版部 | 自社教材の開発・外販で収益化 |
| 模試センター | 自社模試の規模拡大、データによる指導精度↑ |
| 講師養成アカデミー | 学生講師の品質底上げ |
| 私立中学とのリレーション | 学校説明会の共催、入試情報の精度↑ |
| 映像配信スタジオ | オンラインコースの品質↑・全国展開 |
| 不動産・銀行 | 駅前一等地の取得、出店資金の調達 |
| 小規模塾の M&A | 生徒と講師ごとエリアを取得 |

### 3.10 メタ目標 — 参考：個人資産（E12）
二層のゴールを用意し、プレイスタイルを分岐させる。

| ゴール | 指標 | 到達イメージ |
|--------|------|--------------|
| 経営者として | 企業価値・塾長の個人資産・上場 | 「全国チェーンの創業者」 |
| 教育者として | 累計合格者数・生徒満足度・**卒業生の評判** | 「あの塾長に習ってよかった」 |

エンディング／称号は両指標の組み合わせで変わる（例：儲かったが評判は最悪／赤字すれすれだが伝説の塾）。

## 4. 倫理ジレンマ・イベント（差別化の柱③）
倫理は能力値で終わらせず、**選択肢として**提示する。

| イベント | 選択肢A（短期の得） | 選択肢B（長期の信頼） |
|----------|---------------------|------------------------|
| 特待生の“実績水増し” | 1人に多数校を受験させ合格数を稼ぐ | 本人の志望に沿った受験のみ |
| 成績不振の6年生 | 志望校を下げさせ合格率を守る | 本人の挑戦を支える（不合格リスク） |
| 宿題量の増加要望（熱心な保護者） | 全体の宿題を増やす | 個別対応でストレス管理 |
| 人気講師の過重労働 | コマ数を増やして売上確保 | 休ませて講師の離職を防ぐ |
| 上位クラス選抜テスト | 下位生を退塾に誘導 | 補習クラスを新設（コスト増） |

- Aを選ぶと短期の数字は良くなるが、**隠れパラメータ「信頼」**が下がり、一定確率で炎上・行政指導・口コミ急落が起きる。
- 教室長の倫理能力が低いと、委任中に勝手にAを選ぶことがある（委任のリスク）。

## 6. シミュレーションモデル（骨子）

週次処理の概略。係数はプロトタイプで調整する。

```
# 1. 需要（入塾希望者）
潜在需要[エリア, 学年] = 小学生人口 × 中受率(年・エリア) × 季節係数(週)
魅力度[塾] = w1·ブランド力(合格実績) + w2·口コミ総合 + w3·施策効果
           − w4·価格指数 + w5·立地(駅距離)
入塾者[塾] = 潜在需要 × softmax(魅力度)[塾] × 体験→入塾率(教室長の営業力)

# 2. 退塾
退塾確率[生徒] = base + a·max(0, ストレス−閾値) + b·(成績低下) + c·(価格不満)
               − d·面倒見評価

# 3. 学力
Δ偏差値[生徒] = 授業品質(講師・教材) × 意欲 × クラス適合度(レベル差)
              − 過負荷ペナルティ(ストレス)

# 4. 会計
売上 = Σ在籍 × 月謝/4.3 + 講習・特訓・模試・教材
費用 = 講師コマ数 × 時給 + 社員給与 + 家賃 + 教材原価 + 施策費 + 償却

# 5. 年次（2月）
合格確率[生徒, 学校] = sigmoid(k · (偏差値 − 学校偏差値) + 当日運)
ブランド力(翌年) = 旧ブランド力 × 減衰 + Σ(合格者 × 学校ランク重み)
```

- **遅延報酬**：6年生への投資（特訓・講師配置）は当年の利益を圧迫するが、ブランド力として翌年以降の入塾者を押し上げる。
- **規模の経済**：模試受験者数が増えると「偏差値精度」が上がり指導効率↑ → 大手化の意味をゲームで表現。

## 7. 開発スコープ案

### MVP（縦切り：1教室×1年度）
- 1エリア・1教室・競合2塾
- コース：学年別本科3種＋夏期講習
- 生徒エージェント（学力・意欲・ストレス・志望校）
- 講師（社員／学生）と教室長（委任トグル1〜2種）
- 施策カード5種、口コミ4軸
- P&L・5週推移・年度報告書・合格発表演出
- **検証したいこと**：週次ループの手応え、2月の合格発表が「報酬」として機能するか

### α（多教室・2年度以上）
- 3エリア・最大10教室、委任トグル全種
- 自社教材の五角形、倫理イベント
- 競合AIの能動的な行動

### β〜正式版
- 周辺施設、M&A、上場、全国展開
- 少子化・入試改革などの長期イベント
- 二層ゴールとエンディング分岐

### 技術スタック（推奨）
- **TypeScript + React（モバイルファーストのWebアプリ／PWA）**
  - 参考ゲームの主画面はほぼ「カード・グラフ・表」の UI で、Web 技術で十分表現できる
  - シミュレーション本体は UI から独立した純粋な TS モジュールにし、ユニットテストとバランス調整用のヘッドレス実行を可能にする
- マップは当初 2D の簡易地図、のちにアイソメトリック表現を検討
- セーブはローカル（IndexedDB）から開始

## 8. リスクと配慮

| リスク | 対策 |
|--------|------|
| 実在の塾・学校名の使用 | 塾・学校名はすべて架空。偏差値帯や地域性のみリアルに寄せる |
| 中学受験の過熱を煽る印象 | 倫理ジレンマと「教育者としてのゴール」で、詰め込みが最適解にならないバランスにする |
| 生徒エージェントの計算負荷・情報過多 | 生徒は数値で管理し、UIでは「気になる生徒」だけを抽出して提示 |
| 参考ゲームとの類似 | 参考にするのはメカニクスの構造のみ。名称・アート・UI・テキストはすべて独自に制作 |
| 年1回の報酬までの間延び | 模試結果（毎月）・講習の山・競合イベントで中間報酬を配置 |
