# 参考ゲーム分析：コーヒーショップ経営シミュレーションから抽出した「経営シムのエッセンス」

> 対象：提供された画面キャプチャ13枚（コーヒーチェーン経営シミュレーション）
> 目的：中学受験塾経営シミュレーションの設計に転用できる「仕組み」を抽出する。
> ※ 参考にするのはゲームメカニクスの構造のみで、名称・アート・UI デザインは流用しない。

## 2. 抽出したエッセンス（12項目）

### A. コアループ

**E1. 週単位のターン制＋即時フィードバック**
日付が1週ずつ進み、毎週「売上・費用・利益・前週比」が返る。
→ *判断 → 1週待つ → 結果を読む → 調整* の短いループがゲームの心拍になっている。

**E2. 小さく明快なレバー**
価格の ± 、メニュー ON/OFF、施策の採用/不採用。どれも1タップ。
→ 操作は単純、**結果の因果は複雑**。この非対称が「考える楽しさ」を生む。

**E3. トレードオフが常に存在する**
値上げ→粗利↑・販売数↓、施策→集客↑・固定費↑、店長年俸↑→能力↑・人件費↑。
→ どのレバーにも「得るもの」と「失うもの」がある。正解が一つに決まらない。

### B. 情報設計

**E4. 会計で語る（P&L）**
現実の損益計算書と同じ科目で結果を返す。前週比が全行に付く。
→ プレイヤーは「どこで儲けてどこで損しているか」を自力で診断できる。学習効果も高い。

**E5. 多層の可視化（数値 → トレンド → 物語）**
数値（P&L）→ グラフ（5週推移）→ 人の声（レビュー）と、抽象度の違う3層で同じ現実を見せる。
→ 数字が苦手な人はレビューから、得意な人は P&L から入れる。

**E6. 多軸評価**
レビューは「値段・商品・サービス・雰囲気」に分解される。商品ごとにも星がある。
→ 「総合4.3」の内訳がわかるので、**どこを直せば上がるか**が明確。

### C. 市場と外部環境

**E7. 名前のある競合とシェア**
競合は抽象的な「市場」ではなく、名前・住所・ブランドを持つ店。
→ 「あの店に勝つ」という具体的な動機と、ライバルとの物語が生まれる。

**E8. 外部変動（季節性・相場・地域税）**
温/冷の季節交代、豆の相場、都市ごとの税。
→ プレイヤーがコントロールできない要素が「読み」と「備え」を要求する。

### D. 成長とスケール

**E9. 委任による抽象度の引き上げ**
店長に業務を委任すると、その店は自動運転になる。成果は店長の能力次第。
→ 1店舗の細かい操作 → 多店舗の人事・戦略へと、**プレイヤーの役割が成長に合わせて変わる**。

**E10. 垂直統合と周辺事業**
自社ブレンド（原材料）、ロースター、不動産、銀行、広告代理店…。
→ 本業が回り出した後の「次の目標」。原価構造そのものを変えられる中盤の醍醐味。

**E11. 多都市展開**
13都市に数百店舗。都市ごとに競合・税・地図が違う。
→ 同じ勝ちパターンが通用しない新天地 = リプレイ性。

### E. メタ目標と没入

**E12. 二層のゴール＋キャラクター**
企業価値（会社）と個人資産（CEO）が別にある。店長が「こんにちは社長」と話しかけ、客が顔付きでレビューする。
→ 数字のゲームに**人格と所有感**を与える。「自分の会社」「自分の店長」という愛着。

## 3. 逆に「足りない／弱い」と感じた点（差別化の余地）

| 観察 | 改善の方向 |
|------|------------|
| 週次で結果は出るが、**長期投資のリターンが遅れて返ってくる仕組み**は弱い | 塾は「今年の投資が来年の合格実績になる」遅延報酬型。ここを核にできる |
| 顧客は集計値。**個人の顧客が成長する物語**はない | 塾なら生徒一人ひとりの学力推移・合否というドラマがある |
| 倫理能力は能力値の一つに留まる | 塾は「詰め込み・実績水増し」など**倫理ジレンマ**をゲームの選択肢にできる |
| 季節性は需要量の変化のみ | 塾は**年間カレンダー**（講習・模試・入試）そのものが構造を決める |
