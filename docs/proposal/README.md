## 要約
- 参考ゲームの核は「週次ターン × 1タップのレバー × 会計・グラフ・口コミの多層フィードバック」と「店長への委任で多店舗へスケール」。
- 塾版はこれを土台に、次の3本柱で差別化する。
  1. **遅延報酬**：2月の入試結果が「合格実績」になり、翌年の集客を左右する（週次＋年次の二重ループ）
  2. **生徒エージェント**：学力・意欲・ストレス・志望校を持つ生徒が育つ／脱落する
  3. **倫理ジレンマ**：実績水増し・詰め込みなど、短期の数字と長期の信頼の選択
